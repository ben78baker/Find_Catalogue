## Description

Find Catalogue is a private, structured record for archaeological and field finds.

Start a record at the moment of discovery with a photograph, time and location, or catalogue an existing find later. Each record receives a permanent log number and can grow with identification, material, confidence, interpreted timeline, measurements, observations, research notes, sources and physical storage details.

Key features:

• Rapid Instant Find capture
• Manual records for previously discovered objects
• Original photographs preserved in app-owned storage
• Permanent sequential catalogue numbers
• Search and filters across the complete catalogue
• Individual and result-set map views
• CSV and PDF sharing
• PDF-and-photos ZIP bundles with saveable images
• Explicit control over whether shared files include exact coordinates

Your catalogue is stored locally without an account, advertising or analytics. Core record keeping works offline. Interactive map tiles require a network connection and are loaded from OpenStreetMap only when you open a map.

Whether you are recording coins, buttons, fittings, tools, fragments or objects still awaiting identification, Find Catalogue keeps observations separate from later research and interpretation.

## App Review notes

Find Catalogue is a local-first personal catalogue. It has no sign-in, account, subscription, advertising or in-app purchases.

Review paths:

1. **Instant Find** requests camera and location access. Cancelling the initial camera returns to the home screen.
2. **Create Find Record** allows an existing photograph and manually entered date/location. A photograph is required before saving.
3. **View Records** searches and filters saved records. Its Map button displays only records in the current result set that have usable coordinates.
4. Sharing is available on each record and from the records list. The reviewer must explicitly choose whether exact coordinates are hidden or included.

Interactive maps request base-map tiles from OpenStreetMap. Record titles, photographs, notes and the catalogue database are not uploaded to a developer service.

No demonstration account is required.
